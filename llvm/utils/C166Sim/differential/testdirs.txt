# The lit targets this target has tests in, one per line.  A line is a
# directory or a single test file; the clang driver tests are files because
# the directory they live in is the whole clang driver suite.
#
# A test not named here is a test CI does not run, which is how the clang
# side came to be running only its two driver tests: everything else under
# clang and the disassembler's own directory were written and then never
# checked again.
#
# There are two readers and they must not drift apart: the workflow runs lit
# over these, and checktools.sh reads the RUN lines in them to work out which
# tools the build has to produce.  Adding a directory to one and not the other
# is what let a test needing "opt" reach CI - the checker written to catch that
# was not looking at the directory the test was in.
